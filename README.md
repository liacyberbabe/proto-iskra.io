# Iskra Exchange — Luxury B2B SaaS Website

A responsive static website for Iskra Exchange LLC, designed around the supplied Iskra visual identity: deep burgundy, champagne gold, ivory, elegant serif typography, star/spark motifs, and the "BRIGHT IDEAS. BOLD SOLUTIONS." tagline.

## Files
- `index.html` — complete website
- `styles.css` — responsive visual system
- `script.js` — mobile navigation and lightweight reveal behavior
- `favicon.svg` — Iskra spark favicon

## Deploy
Upload the files to a GitHub repository and enable GitHub Pages under Settings → Pages → Deploy from a branch → main → root.

## Custom domain
After GitHub Pages is enabled, connect `iskraexchange.cc` through the repository Pages settings and configure the DNS records at your domain provider according to GitHub's current instructions.

## Email
The contact CTA currently uses `hello@iskraexchange.cc`. Change it in `index.html` if your preferred inbox is different.
